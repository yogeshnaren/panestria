# Illustrative fixtures

These are schema/coordinate/protocol examples, not observed vendor runs, fetched pages, valid real approvals or application test success. Implementing tests expand them into the scenario families in the test catalog.

The UTF-8 passage fixture records exact retained bytes including a non-ASCII character. Bigint event seq is decimal text, not a JS Number. Goal budget uses canonical decimal-string money. Synthetic JSONL streams are hand-authored shape examples; exact vendor protocol compatibility still needs sanitized real recordings and live gates. Approval preview digest is deliberately illustrative and must not authorize anything.
