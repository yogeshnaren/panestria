## Conditional choices stay visible

- Additional harnesses such as Gemini, Cursor, OpenHands or Agent Zero are R6/R7 adapter candidates; compatibility, sanctioned access and security proof decide adoption. Two approved worker adapters already suffice for the chosen MVP.
- Advanced engines, memory frameworks, telemetry backends, gateways and distributed workflow infrastructure are alternatives. Record an ADR/benchmark before adoption; naming them does not require installing them all together.
- Optional wake-word/ambient capture remains disabled until separately consented and tested. Phone access and proactive notification/scout schedules require explicit owner setup.
- Fine-tuning/offline learning needs sufficient consented labels and paired evidence. Decay/utility-based deletion needs lineage, pin/retention protection and dry-run evaluation.
- REA/reverse-engineering capability is retained for authorized objectives; any adopted source/version/license/runtime gets separate scoped review.

Mandatory target behavior cannot be removed silently. Record any changed scope or deliberate deferral with parent ID, reason, owner decision and destination phase. A research candidate can be evaluated and rejected without blocking release if the required target behavior is satisfied by another supported implementation; unresolved candidates remain visible. Completion of all code does not justify a SOTA leaderboard claim without independent reproducible comparative evidence.
