# Original selected Build inputs in confirmed offline references

This AOS-012-S6/MVP-X11 component fills the original selected-context gap without
guessing historical inputs or retaining unbounded native logs. Existing private
native return receipts record an exact bounded typed header/file metadata manifest
from the controller's original PUBLIC input. The header contains the task/plan
instructions already retained canonically; file metadata contains paths, hashes
and byte counts, without file content. It supplies no filesystem or task authority.

Only the existing explicit/opt-in confirmed-merge capture reads those exact
original blobs from the protected immutable Git tree. Strict relative paths,
bounded output, size/hash/UTF8 checks and exact reconstructed original request
SHA256 fence copying. Missing/invalid data cannot be reconstructed from today's
launcher, plan, model selection or other files. Capture failure preserves the
confirmed merge and starts no new inference or worker.

Version3 archives retain original binding/receipt and selected-context parts;
the standalone reader checks their hashes, scope, original manifest and request
identity without a database, Git, auth, certificate or model. Version1/2 and absent
original metadata remain immutable/UNKNOWN. Default viewing stays metadata only;
one explicit invocation selection reveals its bounded selected input locally.
Selected input excludes fixed harness prompts, later tool conversations, native
outputs and physical network observation. No model/context qualification is inferred.

Existing private archive caps, manifest-last publication, deduplication, no
automatic deletion and separate capture failure reporting remain. Storage stays
within the existing 1MiB capture/8MiB history limits. Local-reference purpose and
UNKNOWN training rights/DENIED export remain; no memory or training promotion.

Required checks: actual disposable PG/Git/MCP/Docker two-worker independent final
checks and exact scripted test-owner merge, copied offline view of exact original
pre-edit bytes/new-file empty selection, tampered/missing metadata/input/scope
refusal, legacy UNKNOWN compatibility and unchanged capacity preservation. Native
generation/account/auth/certificates remain labeled fixtures. No owner service,
database, profile, provider, backup or original release evidence is changed.
