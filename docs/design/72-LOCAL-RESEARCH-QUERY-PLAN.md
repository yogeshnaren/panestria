# Bounded local query proposals

Read the existing immutable PUBLIC research request/question using its canonical
owner/project/task scope and protected bytes. Keep the task CREATED/READY with
no attempt or web authority. The local planner sees a512-byte question prefix,
its source hashes and the current policy/version/epoch binding; never source
instructions, provider credentials or authority from model output.

The exact intent/input artifact and event commit before local inference. A
project/task lock serializes one intent per request, with same-key receipt replay
and no retry of uncertain work. Revalidate immediately before prompt disclosure
and output publication. Reuse the existing bounded cached CPU model transport
and generic protected synthesis artifact writer; do not invoke synthesis's
passage-verification lifecycle or claim semantic support.

The closed response allows up to three distinct bounded query strings. The
retained proposal includes exact input/output/model/digest/prompt references,
usage and request latency. Artifacts precede their last-write canonical event.
No task state, attempt, check verdict, collection grant or training authority
is inferred from the proposal. Historical export validates original artifacts
and scope, needs no model cache/runtime, and can supply plain queries to the
separately qualified collector after owner review.

This is basic local planning, not a full adaptive research controller. Broader
iteration, qualified support/contradiction assessment and actual service/cumulative
release evidence remain pending. Preserve original actual CPU observations and
fixture failures at their own source; do not call them a new candidate's gate pass.
