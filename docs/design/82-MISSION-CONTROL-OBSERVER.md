# Explicit local Mission Control observer

Deliver one reviewable AOS-028 outcome: React/TypeScript/Vite metadata observation
with OpenAPI-generated contracts, real cookie pairing and canonical reconciliation.
Keep original intake, artifact/diff/evidence, approvals, phone and gate obligations
open. The terminal remains the action interface during this slice.

The explicit CLI reuses `serve_activity`, its exclusive socket, process-owned
shutdown and existing scope. It attaches only fixed production assets plus
existing session routes. The standalone activity profile remains unchanged. No
new ledger, migrations, model runtime, job endpoint or provider choice is added.
Built assets are an explicit trusted local input bounded in memory and loaded
once; static paths never map a request path onto the filesystem.

Mission session hashes use a distinct purpose and exact origin. A fixed namespace
selects an origin-derived cookie name; default Ask sessions keep their original
name and service. Shared SessionService retains one-use/expiry/revocation/CSRF
rules. BrowserSecurity supplies exact host/origin checks, no-store, CSP, frame/
URL guards and request caps. Pair-code is CLI bearer only; a browser never needs
the bearer. Pairing/logout can mutate auth state, never goals/policy/work. An
outstanding pairing code for the same project may be invalidated by a later issue,
as already specified by SessionService. Existing sessions are not revoked.

The client streams only notification frames. It advances display and replay
cursor after a validated canonical JSON page, with bounded 50-row backfill,
200-row metadata display, UUID deduplication and BigInt sequence comparisons.
The global high-water snapshot cursor does not skip unseen goal events. Retention
resync drops the old event buffer. Reconnect backs off, rereads canonical state
and resumes after the last canonical delivered cursor. Quiet streams reconcile
at ten seconds; stale observations expire at fifteen seconds. Request deadlines
and abort guards prevent an old selection or ended session from publishing a late
view. Explicit logout stops authenticated polling so confirmation persists.

The React tree escapes untrusted text; it has no raw HTML renderer, localStorage,
service worker or optimistic goal transitions. Error bodies are not echoed.
Canonical status, task state, held/unknown capacity and acceptance NONE stay
separate. No independent phone/security/privacy authority is implied by a desktop
cookie. Chromium evidence is not Firefox/phone/live-resource/full G3 acceptance.

CI adds frontend work only to the existing quality/platform jobs, preserving all
six required checks and all current behavioral lanes. Dependency versions and
integrities are locked; install scripts are disabled. Production runtime notices
retain React/react-dom/scheduler MIT terms. No external product source is copied
or reconstructed; this slice reuses internal auth/activity/SSE implementations and
ordinary dependency distributions. There is no REA engine installation/execution.
