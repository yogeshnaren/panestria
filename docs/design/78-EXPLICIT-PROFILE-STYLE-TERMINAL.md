# Explicit encrypted style terminal

Complete a usable AOS-017-S4 editing surface over the existing owner-profile
HTTP operations; do not create another profile store or implicitly enable
sensitive mode. The client has a private fixed-loopback scope and existing token.
Canonical project activity verifies owner/project before any clear view/write.
Five-second total HTTP bounds, response caps, no redirects/proxy environment and
fixed error codes prevent implicit routing/retry and payload-bearing errors.

An explicit owner-review action views only an exact requested profile version.
The UI displays bounded structured preferences and a separate communication
local-context approval. Other profile fields remain masked/undisplayed, in
memory only. Save creates a complete encrypted revision through the existing
API while preserving every other field, approval and expiry. New profiles use
an existing scoped key handle and default to no local-context approval. Freeform
legacy communication is not silently replaced. The existing optimistic version
check protects against concurrent correction/suppression. No charter, policy,
capability, key-store or model option comes from the form.

Editing, reviewing and saving are separate keyboard actions. A form permits one
write attempt after exact review; confirmation, refusal, lost response or an
interruption never resubmits. Lost acknowledgment can mean the immutable server
revision exists; inspect the original profile/version before deciding on another
write. The UI discards the wider clear profile after its write attempt and restores
terminal attributes. Clear preferences are not exported, logged or fingerprinted.
Core dumps are disabled in this terminal process. Terminal/OS capture is not an
erasure guarantee.

No profile API mounting, OS key provisioning, model launch or owner environment
change is performed. Default Ask/activity servers remain unchanged. A supported
qualified personal-mode launcher and local Ask selector are subsequent integration
work. The new command works against the existing explicitly enabled qualified
owner API; it is not a permission to bypass that setup boundary. Actual connected
[observations](../../evidence/profile-style-terminal-2026-10-21/report.json) use
synthetic keys, with no inference or actual desktop keyring. Private examples,
paired presentation quality, model compatibility and full original S4–S6/gates
remain open.
