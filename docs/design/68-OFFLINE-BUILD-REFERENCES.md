# Bounded offline Build references

This narrows AOS-012-S6 to one usable outcome: explicit/opt-in reference retention
after an exact confirmed canonical PUBLIC Build merge. Existing PostgreSQL task,
plan, approval, effect and evidence rows remain authoritative. The archive is a
private derived cache, never a second task store or a permission credential.

The controller obtains a repeatable-read canonical progress observation, demands
COMPLETED plus independently confirmed final checks/exact Git-effect witness,
checks the PUBLIC original contract and copies protected contract/evidence/check
bytes plus the Git diff for the bound base/candidate. Original merge-event time
and binding/receipt/controller-source identities remain source-bound; model
identity is unknown where not actually recorded. Arbitrary native logs are not
copied. A canonical pending/failed/unconfirmed result cannot produce the manifest.

The closed version1 manifest keeps source/classification, scope, input/output and
validation/approval lineage, local-reference purpose, independent UNKNOWN training
eligibility and DENIED training export. Capture is disabled by default. A private
operator flag enables only derived reference capture after a normal owner merge;
manual capture is separately explicit. It does not grant background work, widen
provider/data scope, promote knowledge or supply training consent. Broader S5/S6
and rights-aware reference/candidate/training flows remain required.

Private CAS chunks allow a copied archive to be checked without DB/Git/native
credentials. The reader validates all hashes, sizes, contract/bundle scope/version,
required verdicts and report links; it reports the archived observation, not a
fresh qualification or proof that an arbitrary selected archive is authoritative.
It cannot recompute a complete Git tree without the original baseline/repository.
Diff output stays escaped untrusted text. Explicit owner/project identity is checked.

Preflight budgets bound new payload/metadata bytes and file counts; unchanged
captures deduplicate. Final-manifest publication is last, so interrupted writes
can leave only bounded unreferenced bytes. No cleanup is automatic. The original
merge transaction/effect remains committed even if later cache I/O fails; return
a separate UNAVAILABLE observation, never retry the native worker/merge. Manual
capture after inspecting a completed goal is safe because it only rereads evidence.
No migration or alteration of original evidence is required.
