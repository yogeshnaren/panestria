# Fixed-public native Build qualification

Qualify the existing ProposalDemo controller with the actual pinned Claude Code
adapter, disposable PostgreSQL, cached pinned Docker worker image and a protected
temporary Git destination. This closes the gap between the native no-tools
transport check and controller tests that explicitly use provider fixtures.

Use the existing dedicated private Claude profile and unchanged fixed public
prompt. Two calls are expected: explicit operator compatibility qualification,
then one task proposal. Never enable native tools, download an image, substitute
a provider, read credentials or send owner repository content. The native budget
flag is an estimate; actual native cash remains unknown. No direct SDK/API-key
call is part of this test.

Assert independent verification passes before review, the protected main ref is
unchanged while waiting, a mismatched approval fingerprint is denied, and only an
exact scripted test-owner decision dispatches the merge. Assert durable returned
invocations and one successful effect, plus no implicit provider replay on restart
or repeated start. Retain source-bound JUnit and a small factual report without raw
native output. Failure is evidence, never a reason to replace a required live call
with a fixture.

This is component qualification for one public arithmetic function. Scripted
approval is not human acceptance. It does not certify arbitrary repositories,
native tool integration, Cursor orchestration, full AOS-027a assertions, G1, the
R3 MVP or the actual 14-day owner trial. The old owner demo is preserved.
