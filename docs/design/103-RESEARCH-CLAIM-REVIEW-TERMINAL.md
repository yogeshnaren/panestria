source verification and immutable owner-review service. This introduces no model,
search, grant, new persistence/schema, task completion or automatic support

training authority. Qualified synthesis/support and the full D-1/G2 remain open.

private configuration with `need_model=False`, validates the canonical retained
draft and exact source passages, then opens a real TTY. Cache bytes and model
initialization are unnecessary. Noninteractive invocation refuses without writing.

and again before saving, the existing service rechecks source/current policy/task

verdict/citation/note edits reset full-review progress. No source text is executed

historical reviews exist; a new review is an explicit correction, never adoption

shows their complete SHA256 for separate y confirmation. No partial review or
